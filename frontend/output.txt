Tool execution flow (internal code)
Follow this order when reviewing:

1. LLM decides tools
   → backend/src/agent/nodes/llm.ts
2. Router picks retrieval vs tool node
   → backend/src/agent/nodes/route.ts
3. Find pending tool calls
   → backend/src/agent/nodes/pending.ts
4. Execute retrieve (RAG)
   → backend/src/agent/nodes/retrieval.ts
   → backend/src/rag/search.ts
5. Execute getMortgageRate
   → backend/src/agent/nodes/tool.ts
   → backend/src/tools/getMortgageRate.ts
6. Graph wiring
   → backend/src/agent/graph.ts
7. State capture (what gets recorded)
   → backend/src/agent/state.ts
   → backend/src/agent/flow.ts
